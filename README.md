# 🏦 Bank Loan Analysis & Power BI Dashboard

## 📌 Project Overview

An end-to-end **Bank Loan Analysis project** designed to evaluate lending portfolio performance, loan quality, borrower characteristics, and key financial KPIs using **SQL and Power BI**.

The project transforms raw loan data into actionable business insights through SQL analysis and three interactive Power BI dashboards covering **Summary, Overview, and Details**.

## 🎯 Business Objective

The objective is to monitor and analyze:

* Loan application and funding performance
* Total amount received from borrowers
* Good vs. Bad loan performance
* Interest rate and Debt-to-Income (DTI)
* Monthly lending trends
* Regional loan distribution
* Loan purpose and term analysis
* Borrower employment and home ownership patterns

These insights support **data-driven lending, portfolio monitoring, and risk assessment**.

## 🛠️ Tools & Technologies

* **SQL / SQL Server** – Data analysis and KPI calculations
* **Power BI** – Interactive dashboards and visualization
* **DAX** – KPI, MTD and MoM calculations
* **Excel / CSV** – Source data preparation

## 📊 Key KPIs

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average DTI
* Good Loan %
* Bad Loan %
* Good/Bad Loan Applications
* Good/Bad Loan Funded Amount
* Good/Bad Loan Amount Received

MTD and MoM analysis was incorporated to monitor changes in lending performance over time.

## 📈 Power BI Dashboards

### 1. Summary Dashboard

Provides an executive-level view of loan portfolio KPIs, including overall performance and Good vs. Bad loan analysis.

### 2. Overview Dashboard

Analyzes lending trends across:

* Monthly trends
* States / regions
* Loan terms
* Employee length
* Loan purpose
* Home ownership

### 3. Details Dashboard

Provides a consolidated view of loan-level information, borrower profiles, and portfolio performance for detailed analysis.

## 🔎 SQL Analysis

SQL was used to build and validate key business metrics, including:

* Aggregations using `COUNT`, `SUM`, and `AVG`
* Monthly KPI analysis
* Good vs. Bad loan segmentation
* Loan status analysis
* State-wise analysis
* Loan purpose analysis
* Employee length analysis
* Home ownership analysis
* Filtering and sorting for business insights
* Dashboard result validation


The SQL analysis was also used to validate dashboard results under different filters.

## 💡 Key Business Areas Analyzed

**Portfolio Performance:** Applications, funded amount and amount received.

**Loan Quality:** Good loans (Fully Paid/Current) versus Bad loans (Charged Off).

**Risk Analysis:** Interest rate, DTI, loan grade, sub-grade and loan status.

**Borrower Analysis:** Employment length, home ownership, loan purpose and geographic location.
